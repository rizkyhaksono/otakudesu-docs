# Security Policy

## Supported versions

Security fixes are applied on the default branch. This repository publishes a static documentation site.

## Reporting a vulnerability

Report security issues privately through [GitHub Security Advisories](https://github.com/rizkyhaksono/otakudesu-docs/security/advisories/new).

Please do not open a public GitHub issue for a suspected vulnerability. Include the affected path or dependency, the advisory id if you have one, and steps to reproduce the problem.

We will acknowledge valid reports and coordinate a fix before public disclosure.
